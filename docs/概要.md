# 札幌市公共施設予約 空き状況監視システム（概要）

## これは何？

[札幌市公共施設予約情報システム](https://yoyaku.harp.lg.jp/sapporo/) を自動で見回り、屋外サッカー・フットサル系施設に**空きが出たらDiscordにスマホ通知する**、個人用の見張り番システムです。

## 何がうれしいか

キャンセル等で予約が空く瞬間はいつ来るかわからず、手動でサイトを見張り続けるのは現実的ではありません。このシステムが代わりに15分おきに見に行き、空きが出た瞬間だけ知らせてくれます。

## 監視の中身（ざっくり）

- **対象**：屋外サッカー場・フットサル場など、市内61施設（優先度高めの18施設は15分おき、残り43施設は1時間おき）
- **期間**：今日から2週間先まで
- **通知する条件**：
  - 曜日ごとに時間帯を指定（初期設定：平日は夜18〜22時、土日は終日）
  - **連続2時間以上とれる空きのみ**通知（1時間だけの飛び石は対象外）
  - 先着予約・抽選申込のどちらの空きも対象
- 通知には施設名・日付・時間・その日付の予約画面への直リンクが入る

## 裏側の仕組み（ざっくり）

```
15分ごとに自動起動
   ↓
札幌市のサイトへ空き状況を問い合わせ
   ↓
前回の記録と比較して「新しく空いた」ところだけ抽出
   ↓
条件に合えばDiscordへ通知
```

- プログラム自体はGitHub上に置いてあり、`cron-job.org`という外部の無料タイマーサービスが15分ごとに起動の合図を送っています（GitHub自身の定期実行機能はおまけの保険として併用）
- 運用コストは基本0円
