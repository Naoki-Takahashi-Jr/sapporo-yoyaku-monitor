### 資格情報の管理

| 資格情報 | 保管場所 | 権限範囲 | 備考 |
|---|---|---|---|
| `DISCORD_WEBHOOK_URL` | GitHub Actions Secrets | 対象チャンネルへの投稿のみ | `gh secret set DISCORD_WEBHOOK_URL -R Naoki-Takahashi-Jr/sapporo-yoyaku-monitor`。漏えい時は Discord 側で Webhook を再生成して再設定 |
| GitHub PAT（fine-grained） | cron-job.org のジョブ設定（リクエストヘッダ） | 本リポジトリの Actions: Read and write のみ | workflow_dispatch の起動用。**有効期限: 2027-06-11 — 期限までに再発行して cron-job.org のジョブヘッダを更新すること**。失効すると起動が401で失敗し cron-job.org からメール通知が来る（GitHub schedule のバックアップ起動は継続） |
| cron-job.org APIキー | ユーザー管理（Console → Settings → API） | cron-job.org アカウントのジョブ操作 | ジョブの作成・変更に使用。日常運用では不要 |

## 4. 外部サービス・接続先

| 接続先 | プロトコル | 用途 | 認証 | 備考 |
|---|---|---|---|---|
| `yoyaku.harp.lg.jp` | HTTPS (443) | 空き状況の取得（GetDay API） | 不要（匿名） | 札幌市公共施設予約情報システム（HARP基盤）。**Imperva Incapsula（WAF）配下**だが GitHub Actions の IP からのアクセスも実証済みで問題なし。高頻度時に一時的な HTTP 500 あり（機能設計書9章） |
| `discord.com` | HTTPS (443) | Webhook 通知 | Webhook URL 自体が資格情報 | レート制限 429 対応実装あり |
| `github.com` | HTTPS (443) | コード・状態の git push/pull | `GITHUB_TOKEN`（自動発行）／ローカルは gh CLI | — |
| cron-job.org | HTTPS (443) | **GitHub Actions の定時起動（外部cron）**。15分ごとに GitHub API の workflow_dispatch を呼ぶ | GitHub PAT（ジョブ設定内）／管理は cron-job.org APIキー | ジョブID `7797297`、タイムゾーン Asia/Tokyo、6:00〜23:45 の 0/15/30/45分。起動失敗が3回連続すると登録メールへ通知 |

アウトバウンド HTTPS のみ。インバウンド・常駐サーバー・データベースは存在しない。

### ローカルでの実行方法

```bash
pip install -r requirements.txt
python src/monitor.py --dry-run --limit 3      # 通知・保存なしの動作確認
$env:DISCORD_WEBHOOK_URL="..."                  # （PowerShell）通知まで試す場合のみ
python src/monitor.py
```

注意：ローカルで `--dry-run` なし実行すると `state/snapshot.json` が更新される。push すると CI の状態と分岐しうるため、検証は原則 `--dry-run` で行うこと。
