# 監視対象施設 優先度一覧

現時点（`config/config.yaml`）で監視している施設を、優先度（Tier）別にまとめたもの。
2026-10-11 に優先度を見直し、屋外サッカー場を優先度低に、屋内施設と5区（中央区・北区・東区・白石区・豊平区）の学校体育館を優先度高にした。
変更前（夏用）の設定は [監視対象施設_優先度一覧_夏用.md](監視対象施設_優先度一覧_夏用.md) に保存している。

| 優先度 | 監視間隔 | 施設数 |
|---|---|---|
| **Tier 1（優先度：高）** | 10分ごと | 24施設 |
| **Tier 2（優先度：低）** | 60分ごと | 37施設 |
| 合計 | | 61施設 |

Tier変更・施設の追加削除は `config/config.yaml` の `tier: 1`／`tier: 2` を書き換えるだけで反映される（コード変更不要）。
